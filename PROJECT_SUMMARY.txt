🚀 QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: DATABASE SETUP
  1. Open MySQL Client (phpMyAdmin or MySQL CLI)
  2. Run: database_setup.sql
  3. Verify: project_management_db created with 10 tables

STEP 2: CONFIGURE CONNECTION
  1. Open: db_connect.php
  2. Update database credentials:
     - DB_HOST: localhost
     - DB_USER: your_username
     - DB_PASS: your_password
     - DB_NAME: project_management_db

STEP 3: DEPLOY FILES
  1. Copy all files to web server (Apache/Nginx)
  2. Set permissions: chmod 755 directories, chmod 644 files
  3. Ensure PHP 7.0+ with MySQLi extension

STEP 4: ACCESS DASHBOARD
  Open browser and navigate to:
  http://localhost/ProjectDashboard/index.html
