📊 Dashboard System - Quick Start Guide

Get your Monitoring and Project Management Dashboard up and running in minutes

🚀 Installation Steps

Step 1: Prerequisites

Make sure you have the following installed:

  • Web Server (Apache or Nginx)
  • PHP 7.0 or higher with MySQLi extension
  • MySQL 5.7 or MariaDB 10.2+
  • Modern web browser

Step 2: Database Setup

  1. Open your MySQL client (phpMyAdmin or MySQL CLI)
  2. Execute the contents of ../settings/database_setup.sql
    mysql -u root -p < ../settings/database_setup.sql
  3. This will create the database and sample tables

Step 3: Configure Database Connection

  1. Open settings/db_connect.php
  2. Update the database credentials:
    define('DB_HOST', 'your_host'); define('DB_USER', 'your_username'); define('DB_PASS', 'your_password'); define('DB_NAME', 'project_management_db');
  3. Save the file

Step 4: Deploy Files

  1. Copy all project files to your web server's public directory
  2. Ensure proper permissions:
    chmod 755 /path/to/ProjectDashboard chmod 644 /path/to/ProjectDashboard/*.php

Step 5: Access the Dashboard

Open your browser and navigate to:

http://localhost/ProjectDashboard/index.html

⚙️ Configuration

Database Configuration

Edit settings/db_connect.php to set your database credentials:

<?php define('DB_HOST', 'localhost'); define('DB_USER', 'root'); define('DB_PASS', 'password'); define('DB_NAME', 'project_management_db'); ?>
Note: Keep your database credentials secure. Never share them publicly.

🔒 Security Recommendations

For Production Use:

  • Implement user authentication
  • Use parameterized queries to prevent SQL injection
  • Validate all user inputs
  • Implement HTTPS for all connections
  • Use session management and cookies securely
  • Hash passwords with bcrypt or password_hash()
  • Implement CSRF protection tokens
  • Set up proper file permissions
  • Enable web server security headers
  • Keep PHP and MySQL updated
Warning: This dashboard is provided as a demo. Ensure proper security measures before deploying to production.

🎨 Customization

Changing Colors

Each CSS file uses CSS variables for easy color customization. Find the :root section and modify:

:root { --primary-color: #800000; --secondary-color: #660000; --success-color: #10b981; /* ... more variables ... */ }

Adding New Pages

  1. Create a new HTML file (e.g., newpage.html)
  2. Copy the sidebar and header structure from existing pages
  3. Create a corresponding CSS file in the css/ folder
  4. Add navigation link in the sidebar

🆘 Troubleshooting

Connection Issues

Problem: "Connection failed" error

Solution:

  • Verify MySQL is running
  • Check database credentials in settings/db_connect.php
  • Ensure MySQLi extension is enabled in PHP

Page Not Found

Problem: 404 errors

Solution:

  • Verify all files are uploaded to the server
  • Check file permissions (should be readable)
  • Verify the correct URL path

Styling Issues

Problem: CSS not loading

Solution:

  • Clear browser cache (Ctrl+Shift+Del)
  • Check CSS file paths are correct
  • Verify CSS files exist in the css/ folder
